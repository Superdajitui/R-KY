## 部署备忘

- **仓库**：https://github.com/Superdajitui/R-KY （Public）
- **发布目录**：`main` 分支的 `/docs`
- **推送方式**：SSH over 443（`ssh://git@ssh.github.com:443/Superdajitui/R-KY.git`）
- **密钥**：`~/.ssh/id_ed25519_github`（换电脑要重新跑 `tools\设置SSH密钥.bat`）

> **为什么用 SSH 而不是 HTTPS？**
> 这台机器上装了 **Watt Toolkit（Steam++）**，它会把 `github.com` 劫持到
> `127.0.0.1` 做本地反代（hosts 里能看到一整列 `127.0.0.1 github.com`）。
> 它的中间人证书过不了 git 的 schannel 吊销检查，HTTPS 推送必然报
> `CRYPT_E_NO_REVOCATION_CHECK`。而 `ssh.github.com` 不在劫持列表里，
> 也不走 TLS，所以完全绕开了这个问题。

## 本地预览

**双击 `打开网站.bat`** —— 会自动起服务、列出手机可用的地址、检查防火墙，
然后打开浏览器。

```bash
npm start                # 监听所有网卡 → http://127.0.0.1:4321/
npm run preview:docs     # 预览打包产物，并模拟 GitHub Pages 的子路径
```

> **为什么要起服务，而不是直接双击 `index.html`？**
> 浏览器对 `file://` 协议下的自定义字体有 CORS 限制，直接双击打开时
> Anton / Inter 会被拦掉，标题会退化成系统字体（照片不受影响，能正常显示）。

## 在手机 / 平板上打开

同一 Wi-Fi 下的手机、平板可以直接访问，**不需要部署**。有两步：

### 1. 用启动器拿到地址

双击 `打开网站.bat`，它会打印形如 `http://192.168.0.107:4321/` 的地址。
在手机浏览器里输入这个地址即可。

> 服务默认监听 `0.0.0.0`。如果只绑 `127.0.0.1`（回环地址），
> 局域网里的手机根本连不上 —— 这是"其他设备打不开"最常见的原因。

### 2. 放行防火墙（只需做一次）

以管理员身份运行 `tools\放行防火墙.bat`，会自动弹出授权窗口并添加一条
TCP 4321 的入站放行规则。

> **为什么必须手动放行？** 如果你的网络被 Windows 识别为「公用网络」
> （`设置 → 网络和 Internet → 以太网 → 网络配置文件类型`），防火墙会阻止
> **一切**入站连接，而且**不会弹**"是否允许访问"的提示，所以只能手动加规则。
> 启动器会检测这条规则是否存在，缺失时会提醒你。

想撤销这条规则：

```powershell
netsh advfirewall firewall delete rule name="个人网站预览 4321"
```

### 排查清单

| 现象 | 原因 |
|---|---|
| 手机提示"无法访问此网站" | 防火墙规则没加，或没连同一个 Wi-Fi |
| 地址栏输入后跳到搜索引擎 | 漏了 `http://` 前缀 |
| 电脑上能开、手机上不行 | 服务绑到了 `127.0.0.1` 而不是 `0.0.0.0` |
| 想在外面（4G/5G）也能看 | 局域网方案做不到，需要部署到公网 |

## 换照片

素材已经用 `tools/cutout.mjs` 抠好背景（白底 → 透明）。
换一张新证件照后重新跑一遍即可：

```bash
npm run cutout
```

这个脚本做了几件事：

1. **自动判定背景色** —— 在四条边框带里挑颜色最均匀的一条作为背景参考色。
   不能四边取平均，否则底部的深色衣服会把背景色带偏成灰色（这个坑踩过）。
2. **区域生长泛洪** —— 只吃掉与画面边缘连通的背景，所以脸部高光、
   白衣服上的白点不会被误伤成透明洞。
3. **饱和度守卫** —— 背景必须是"灰/白"的低饱和像素。
   只靠颜色距离是不够的：头发与耳朵交界处的抗锯齿渐变同样满足"距离够近"，
   泛洪会顺着这条渐变啃进耳朵，表现为耳朵被咬掉一块锯齿状缺口（这个坑也踩过）。
   白底饱和度是 0，皮肤是 20+，饱和度才是可靠的判据。
   容许上限 = 背景自身饱和度 + 0.09，所以彩色背景也能自适应。
4. **形态学开运算** —— 对背景掩膜做「先腐蚀后膨胀」，清掉仍然渗进主体的背景细缝。
5. **只在边界 3px 内羽化**，主体内部锁死 `alpha=1`。这一步很关键：
   如果主体也按"到背景色的距离"算半透明，去白边的除法会把肤色算成橘色。
6. **unmultiply 去白边** —— 避免深色背景上出现一圈白色描边。
7. **底部渐隐烤进 alpha 通道** —— 让肩膀溶进黑底。
   不用 CSS `mask-image` 是因为 mask + filter + mix-blend-mode 叠在同一个元素上时，
   个别浏览器/驱动组合会把整块渲染成空白。
8. 自动裁掉透明边距，并额外生成一个**霓虹绿双色调版本**（鼠标悬停人物时叠加）。

## 设计说明

**双色系统**（来自 Lando 官网）：绝对黑 `#111112` + 霓虹绿 `#D2FF00`，
没有第三种颜色。想换主色只改 `style.css` 里的 `--neon`。

**首屏纵深**：`KERRY` 在人物之后，`任恺昱` 在人物之前，形成前后夹层的海报感。
实现上依赖 `.hero__title` **不设 `z-index`** —— 一旦设了就会创建层叠上下文，
把两个字一起锁在人物下面。（详见 `style.css` 里的注释。）

**首屏位置微调**：改 `:root` 里这几个变量就能整体挪动构图：

```css
--hero-name-top:15svh;        /* KERRY 距顶部 */
--hero-name-bottom:11svh;     /* 任恺昱 距底部 */
--hero-portrait-h:...;        /* 人物高度 */
--hero-portrait-bottom:0;     /* 人物距底部 */
```

**渐进增强**：所有入场动效都挂在 `html.js` 下。脚本被禁用或加载失败时，
`<noscript>` 会兜底显示全部内容 —— 不会出现"整站空白"。

**无障碍**：完整支持 `prefers-reduced-motion`，键盘焦点有可见描边，
`alt` 文本、语义化标签、`aria` 属性齐备。

## 首屏流体效果

`assets/js/fluid.js` —— 纯手写 WebGL，不依赖任何库。

**原理**（两趟渲染 + 一张乒乓缓冲）：

1. **流场趟**：把上一帧的流场做耗散，然后在鼠标位置注入"鼠标速度"，
   于是光标划过会留下一条自己衰减、平滑扩散的痕迹。
2. **显示趟**：拿流场当位移图去采样人物贴图。R/G/B 三通道用**略微不同的
   偏移量**采样 —— 这点色散是"液体/玻璃"质感的关键，没了它只像画面在抖。
3. 扰动剧烈的地方叠一层霓虹绿，呼应整站的双色系统。

**调强弱**：改 `fluid.js` 顶部的常量即可。

```js
const STRENGTH = 0.20;   // 位移强度（第一版给到 0.62，头盔被涂抹到认不出）
const INJECT   = 14.0;   // 鼠标速度注入倍率
const RADIUS   = 0.16;   // 光标影响半径
const DECAY    = 0.90;   // 衰减速度，越小散得越快
const MAXVEL   = 0.028;  // 位移上限
```

**性能**：流场只用 256×256 跑（位移场本身平滑，不需要高分辨率）；
鼠标离开且流场衰减干净后循环会自己停掉，不空转耗电。

**兜底**：任何一步失败（不支持 WebGL、贴图加载失败、context 丢失、
系统开了"减少动态效果"）都安静退回静态 `<img>`，绝不让首屏变空白。

## 验证脚本（开发用，可删）

```bash
npm run shot           # 截图各版块到 tools/shots/（含手机、平板横竖屏），并收集控制台报错
npm run inspect        # 量首屏元素实际位置，检查是否压盖 / 溢出视口
npm run test:fluid     # ★ 真的用鼠标划过人物，抓三个时刻确认流体效果生效
npm run test:subpath   # ★ 在 /R-KY/ 子路径下实测生产包，部署前必跑
```

前两个用本机 Edge 无头模式驱动，改完样式后跑一遍，比肉眼看可靠 ——
层叠上下文那个 bug 就是这么抓出来的。

**`test:fluid`** 会驱动鼠标在人物上来回划动，抓下
静止态 / 划过中 / 衰减后三个时刻，确认效果真的生效且能正确衰减。
它抓出过两个真 bug：

- **指纹不能读 canvas** —— WebGL 默认 `preserveDrawingBuffer: false`，
  合成后缓冲就被清了，`drawImage` 读回来全黑，永远判断为"没变化"。
  改成对截图本身取指纹。
- **画面变化必须以 WebGL 成功为前提** —— 否则视差和入场动画本身
  就会让截图不同，得到假阳性。

**`test:subpath` 是部署前的关键一步。** GitHub Pages 的项目站点跑在
`/仓库名/` 子路径下，而不是域名根目录。任何一处写成 `/assets/...` 的绝对路径
都会 404，**而这个问题在本地根路径预览时完全看不出来** —— 要等部署完
打开网页发现白屏才知道。这个脚本会：

- 以 `--prefix=/R-KY` 启动服务器，真实模拟子路径环境
- 检查首页的每个资源、照片、字体是否加载成功
- 检查 404 页的样式和「回到首页」链接是否指向正确位置

实测它抓出过一个真 bug：404 页用相对路径引用样式表，在
`/R-KY/任意路径/` 下会被解析成 `/R-KY/任意路径/assets/...` 直接 404，
整页样式全丢。现在由打包脚本注入 `<base href="/R-KY/">` 解决了。

## 踩过的坑（改代码前先看一眼）

1. **`.hero__title` 不能设 `z-index`** —— 一设就创建层叠上下文，把「KERRY」和
   「任恺昱」一起锁在人物之下，前后夹层的纵深效果直接失效。
2. **批处理文件里不要写中文** —— cmd.exe 按字节偏移读 .bat，多字节字符可能被
   切在中间，导致后续命令行错乱（实测会报 `'手机' is not recognized`）。
   所以 `.bat` 全是纯 ASCII 跳板，中文逻辑放在 `tools\*.ps1` 里，
   且 .ps1 必须存成 **UTF-8 with BOM**，否则 Windows PowerShell 5.1 会读成乱码。
3. **不要给 `.hero__portrait` 叠加 mask + filter + mix-blend-mode** ——
   个别浏览器/驱动组合会把整块渲染成空白，症状就是"照片完全显示不出来"。
   底部渐隐已经烤进图片 alpha 通道。
4. **`svh` 要有 `vh` 兜底** —— 不支持 `svh` 时会让整个 `min()` 失效，
   绝对定位的人物尺寸会失控。
5. **404 页的资源路径必须相对站点根** —— 见上面 `test:subpath` 的说明。
6. **抠图不能只看颜色距离** —— 头发与耳朵交界的抗锯齿渐变同样"距离够近"，
   泛洪会顺着它啃进耳朵。必须加饱和度守卫，详见 `tools/cutout.mjs`。
7. **这台机器的 `github.com` 被 Watt Toolkit 劫持到 `127.0.0.1`** ——
   所以 git 必须走 SSH（见上面的部署备忘）。另外 `github.io` 也在劫持列表里，
   意味着**你自己浏览器访问自己的网站会经过 Watt Toolkit 代理**；
   如果你关掉 Watt Toolkit，记得确认 `github.io` 还能正常解析。
8. **插值进 GLSL 的数字必须是浮点字面量** —— JS 会把 `14.0` 渲染成 `"14"`，
   而 GLSL ES 里 `vec2 * int` 非法，着色器直接编译失败。用 `toFixed()` 生成。
9. **下载的素材可能本来就是透明底** —— 这时"自动识别背景色"会把边界上的
   透明像素读成 `rgb(0,0,0)`，然后泛洪顺着黑色把主体暗部整个啃掉。
   `cutout.mjs` 现在会先检查边界透明度，是透明图就直接拒绝运行。
10. **sharp 的 `resize` 先于 `composite` 执行** —— 写成
    `.composite(x).resize(700)` 会先缩到 700 宽再把大图贴上去，
    直接报尺寸不匹配。必须分两步。
11. **sharp 的 `composite` 不允许叠加层大于底图** —— 给旋转留白时要注意，
    留过头（比如 40%）叠加层就会超过底图尺寸而报错。
12. **同一进程内反复写同一个路径会撞 `EBUSY`** —— 批量生成变体时，
    让每个变体写各自的文件名。

## 技术栈

纯手写 **HTML + CSS + JavaScript**，运行时**零依赖、零构建步骤**。
`node_modules` 只在开发和重新生成素材时用到，部署时整个 `tools/` 和
`node_modules/` 都可以不要，只传 `index.html` + `assets/` 即可。
